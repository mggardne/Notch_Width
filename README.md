# Notch_Width
Matlab files for characterizing knee notch width and volume.

M-file icnotch_rdg4.m was used to get ridge height for the CACL study.

M-file notchvols.m was used to get notch volumes.  The M-file function rd_roi7hp.m reads the OsiriX polygon areas.

See the M-file header comments for more information about the individual files.
